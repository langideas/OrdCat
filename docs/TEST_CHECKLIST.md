# OrdCat v0.2 测试验收清单

测试环境：macOS 13 以上；版本号以「右键小猫 → 关于」显示为准。每项通过打 ✅，失败记下现象和截图。

## A. 安装与更新
- [ ] A1 把 OrdCat.app 放进「应用程序」，右键打开能正常启动，右侧出现小猫，菜单栏出现 🐈‍⬛
- [ ] A2 右键小猫 → 关于：显示 v0.2.x；菜单栏第一行也显示版本号
- [ ] A3 点「检查更新」：显示“已经是最新版本”
- [ ] A4 发布更高版本后（或等自动检查）：小猫冒泡“有新版本”，菜单栏版本行显示“可更新到 v…”
- [ ] A5 点「立即更新」：自动下载、退出、替换、重启，关于页版本号变新，聊天记录和设置都还在
- [ ] A6 修改仓库 config/remote.json 的 announcement（换一个 id）后重启 OrdCat：弹出新公告，无需更新版本

## B. 小猫交互（v0.1.4 功能回归）
- [ ] B1 鼠标靠近小猫头：探出更多身体；移开约 0.6 秒后缩回
- [ ] B2 右键 / Control+点击小猫：直接打开设置
- [ ] B3 设置里 API Key、模型输入框可以 ⌘V 粘贴
- [ ] B4 气泡里点「↗ 完整对话」：打开聊天窗口，能看到全部历史；重启后历史仍在
- [ ] B5 聊天窗口 📎 或拖入图片、PDF、文本文件能发送（图片需识图模型）
- [ ] B6 语音：开启后按 ⌃⌥空格 说话，停顿约 1.6 秒自动发送，小猫语音回复
- [ ] B7 在浏览器、备忘录、VS Code 中拖选文字：小猫竖耳朵并冒泡，「帮我看看」「翻译」都能用；剪贴板原内容未被改动

## C. 桌面感知开关与权限
- [ ] C1 按 ⌃⌥D：小猫提示“桌面感知打开啦”，菜单栏变成 🐈‍⬛👀；再按一次关闭并恢复 🐈‍⬛
- [ ] C2 设置 → 感知与记忆 的开关、菜单栏「桌面感知」、快捷键三处状态一致
- [ ] C3 快捷键改成 ⌃⌥P 后立即生效，旧快捷键失效
- [ ] C4 未授权辅助功能时开启：系统弹出授权提示；授权后功能可用
- [ ] C5 关闭感知后提问：「查看当前上下文」中不再有“当前屏幕”内容被发送（回答不引用屏幕）

## D. 感知与回答（核心）
- [ ] D1 打开一个网页文章，问“我现在在看什么？”：能说出标题和要点
- [ ] D2 在 Xcode / VS Code / 终端制造一个报错，问“这个报错怎么解决？”：能引用屏幕上的报错原文并给出改法
- [ ] D3 回答里指向按钮时（如“点哪里保存？”）：屏幕对应位置出现琥珀色高亮框，约 7 秒后消失
- [ ] D4 在图片 / 画布类应用（读不到 AX 文字）中，授权屏幕录制后提问：上下文“读取方式”显示 OCR，能读出画面文字
- [ ] D5 勾选「提问时附带截图」并使用识图模型：模型能描述界面视觉内容；用纯文本模型时关闭此项不报错

## E. 记忆中枢
- [ ] E1 先看一个页面，切到别的应用 10 分钟以上，问“我 10 分钟前看的那个页面讲了什么？”：能召回
- [ ] E2 「查看当前上下文」包含四段：当前屏幕 / 最近 10 分钟 / 相关记忆 / 用户常用
- [ ] E3 上下文顶部显示的 tokens 不超过预算（默认 3500）
- [ ] E4 换模型（如 Groq → Ollama），问前一天看过的内容：仍能召回（记忆不随模型丢失）
- [ ] E5 同一窗口静止不动 2 分钟：设置页“丢弃重复帧”数增加，“保留帧”基本不变
- [ ] E6 「清空记忆」后记忆条数归零，再提问不再召回旧内容；「数据文件夹」能打开本地数据目录
- [ ] E7 记忆保留改为 1 天：超过 1 天的记录在重启后被清理

## F. 隐私与脱敏
- [ ] F1 屏幕上显示 sk-xxxx / gsk_xxxx / ghp_xxxx 类 Key：「查看当前上下文」里显示为 «API Key 已脱敏»
- [ ] F2 显示 “password: 123456” 或 “密码：123456”：显示为 «已脱敏»
- [ ] F3 网页登录框的密码输入框内容从不出现在上下文中
- [ ] F4 打开 1Password / 钥匙串访问 / 密码 App：上下文显示“没有读取到”
- [ ] F5 在「排除应用」填入某个 Bundle ID（如 com.tencent.xinWeChat）：该应用不再被读取
- [ ] F6 用 Little Snitch 或「活动监视器 → 网络」观察：除了你配置的模型接口、GitHub 更新检查外，没有其他联网

## G. 性能（PRD 低功耗指标）
- [ ] G1 感知关闭、空闲 5 分钟：活动监视器 CPU 平均 ≤ 0.1%
- [ ] G2 感知开启、正常使用：CPU 平均 ≤ 2%，提问瞬间可以短暂升高
- [ ] G3 内存：感知关闭 ≤ 40 MB；感知开启 ≤ 80 MB
- [ ] G4 记忆库连续使用一天 ≤ 50 MB
- [ ] G5 目标应用卡死时小猫不卡（AX 超时 0.3 秒）
- [ ] G6 提问到第一个字出现：感知开启时比关闭时多 ≤ 1.5 秒（不含 OCR 慢路径）

## 已知限制
- 每次更新后，macOS 可能需要在「辅助功能 / 屏幕录制」里把 OrdCat 删掉重新勾选（未使用 Apple 开发者签名）。
- OCR 和截图需要 macOS 14 以上。
- Chrome 等部分应用的网页内容 AX 读取有限，此时依赖 OCR。
