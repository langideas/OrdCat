隐私政策

更新日期：2026 年 11 月 19 日

Deutsche Fassung ↓

OrdCat 是一款 macOS 桌面应用。我们的原则是：能在你的 Mac 上完成的，就只留在你的 Mac 上。本政策如实说明 OrdCat 应用和 ordcat.de 网站会处理哪些数据、存在哪里、发给谁。

1. 负责人

Axun Conor，Hedemannstraße 74, 78355 Hohenfels, Baden-Württemberg, 德国。邮箱：hello@ordcat.de。

2. 只保存在你 Mac 上的数据

以下数据保存在 ~/Library/Application Support/OrdCat（或 macOS 钥匙串）中，不会上传到我们的服务器：

  • 聊天记录和话题。
  • 本地记忆：你在使用中产生的屏幕文字摘要（通过系统「辅助功能」读取前台窗口的文字，必要时用 macOS 自带的文字识别），存在本地 SQLite 数据库里，用于小猫理解上下文。存入前会在本地过滤密码框和敏感内容。
  • 你的 API Key 和登录凭证：保存在 macOS 钥匙串。
  • 设置：保存在 macOS 偏好设置中。
  • 语音识别：使用 macOS 自带的语音识别，设备支持时强制在本机完成。

你可以在 设置 → 账号 / 感知与记忆 中导出或清除这些数据；删除应用和上述文件夹即可全部删除。

3. 发给你自己选择的 AI 模型服务商

OrdCat 不提供模型，由你自己配置（BYOM）。当你提问、分享页面、复制文字让小猫看看、使用看图或语音朗读等功能时，相关内容（你的问题、所选的屏幕文字或截图片段、相关记忆片段）会直接从你的 Mac 发送到你配置的服务商，例如 OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、硅基流动，或你本机的 Ollama。这些数据不经过我们的服务器。服务商如何处理数据，以其各自的隐私政策为准。使用本地 Ollama 时，数据不离开你的电脑。

发送前，OrdCat 会在本地尝试给密码、密钥、卡号等内容打码。

4. 账号与任务广场（可选）

只有你注册登录账号后，以下数据才会保存在我们使用的后端服务 Supabase（Supabase Inc.，数据中心位于新加坡）：

数据用途谁能看到
邮箱地址、登录记录用邮箱验证码登录仅你本人和运营者
用户名、显示名称、头像个人资料、广场署名头像公开可访问；名称对登录用户可见
小鱼干余额和流水任务广场奖励仅你本人
你发布的任务（标题、说明、类型、链接、附件）任务广场所有登录用户可见；附件通过公开链接可访问
你提交的回答、使用的模型名称任务广场任务发布者和你本人
订阅状态（如以后开通付费）开通付费技能仅你本人

登录验证码邮件通过 Resend（Resend Inc.，美国）从 noreply@ordcat.de 发出，Resend 会处理你的邮箱地址。

你可以随时在 设置 → 账号 中删除账号，账号和上表中的数据会一并删除。

5. 更新检查与下载

OrdCat 会定期访问 GitHub（GitHub Inc.，美国）检查新版本并下载更新，同时读取一份公开的配置文件（公告等）。GitHub 会像访问任何网站一样处理你的 IP 地址。我们不在这些请求中发送任何个人信息。

6. 付费（尚未开通）

如果以后开通付费技能，支付将由 Lemon Squeezy 作为经销商处理，我们不会接触你的银行卡信息。开通前会更新本政策。

7. 网站 ordcat.de

网站托管在 GitHub Pages（GitHub Inc.，美国）。访问时 GitHub 会处理你的 IP 地址等技术数据以提供网页。网站不使用 Cookie、不使用统计或广告追踪。下载页会向 GitHub 查询最新版本号。

8. 不做的事

  • 不出售、不出租你的数据。
  • 不做广告追踪，没有第三方统计。
  • 不在后台持续录屏或录音。

9. 法律依据和你的权利（GDPR）

我们处理账号数据的依据是履行与你的使用协议（GDPR 第 6 条第 1 款 b 项），更新检查和网站运行基于正当利益（第 6 条第 1 款 f 项）。数据传到欧盟以外（美国、新加坡）时，依据服务商的标准合同条款或欧盟-美国数据隐私框架。

你有权访问、更正、删除、限制处理、数据可携带，以及反对处理。请发邮件到 hello@ordcat.de。你也可以向数据保护监管机构投诉，例如巴登-符腾堡州数据保护与信息自由专员（LfDI Baden-Württemberg）。

10. 未成年人

注册账号需年满 16 周岁。

11. 变更

功能变化时我们会更新本政策，并在此页面标明更新日期。

Datenschutzerklärung

Stand: 19. November 2026

1. Verantwortlicher

Axun Conor, Hedemannstraße 74, 78355 Hohenfels, Baden-Württemberg, Deutschland. E-Mail: hello@ordcat.de.

2. Daten, die nur auf Ihrem Mac bleiben

Folgende Daten werden lokal unter ~/Library/Application Support/OrdCat bzw. im macOS-Schlüsselbund gespeichert und nicht an uns übertragen: Chatverläufe; lokale Erinnerungen (Textauszüge des aktiven Fensters, gelesen über die macOS-Bedienungshilfen bzw. die systemeigene Texterkennung, vorab lokal gefiltert); API-Schlüssel und Anmeldedaten (Schlüsselbund); Einstellungen. Die Spracherkennung erfolgt über macOS und, sofern vom Gerät unterstützt, ausschließlich lokal. Sie können diese Daten in den Einstellungen exportieren oder löschen.

3. Übermittlung an den von Ihnen gewählten KI-Anbieter

OrdCat stellt kein eigenes KI-Modell bereit. Wenn Sie eine Frage stellen oder eine Funktion nutzen, werden die dafür nötigen Inhalte (Ihre Frage, ausgewählter Bildschirmtext oder Bildausschnitt, relevante lokale Erinnerungen) direkt von Ihrem Mac an den von Ihnen konfigurierten Anbieter gesendet (z. B. OpenAI, Anthropic, Google, DeepSeek, Groq, SiliconFlow oder lokal Ollama). Diese Daten laufen nicht über unsere Server. Es gelten die Datenschutzbestimmungen des jeweiligen Anbieters. Passwörter, Schlüssel und Kartennummern werden vor dem Senden lokal möglichst maskiert.

4. Konto und Aufgaben-Marktplatz (optional)

Nur wenn Sie ein Konto anlegen, speichern wir bei unserem Auftragsverarbeiter Supabase Inc. (Rechenzentrum Singapur): E-Mail-Adresse und Anmeldedaten; Benutzername, Anzeigename, Profilbild (öffentlich abrufbar); Guthaben und Buchungen der „小鱼干“-Punkte; von Ihnen veröffentlichte Aufgaben einschließlich Links und Anhängen (für alle angemeldeten Nutzer sichtbar, Anhänge über öffentliche Links abrufbar); Ihre Antworten und den Namen des verwendeten Modells (sichtbar für den Aufgabensteller); ggf. Abostatus. Anmeldecodes werden über Resend Inc. (USA) versendet. Sie können Ihr Konto jederzeit in den Einstellungen löschen; die genannten Daten werden dabei gelöscht.

5. Updates

Die App ruft regelmäßig GitHub (GitHub Inc., USA) auf, um nach Updates zu suchen, diese herunterzuladen und eine öffentliche Konfigurationsdatei zu lesen. Dabei wird Ihre IP-Adresse verarbeitet; personenbezogene Daten senden wir dabei nicht.

Derzeit gibt es keine kostenpflichtigen Funktionen. Künftig würden Zahlungen über Lemon Squeezy als Wiederverkäufer abgewickelt; wir erhalten keine Zahlungsdaten. Diese Erklärung wird vorher aktualisiert.

ordcat.de wird über GitHub Pages (GitHub Inc., USA) bereitgestellt; dabei werden technisch notwendige Daten wie die IP-Adresse verarbeitet. Wir verwenden keine Cookies, keine Analyse- und keine Werbe-Tracker.

Sie haben das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch (Art. 15–21 DSGVO). Kontakt: hello@ordcat.de. Sie können sich zudem bei einer Aufsichtsbehörde beschweren, z. B. beim Landesbeauftragten für den Datenschutz und die Informationsfreiheit Baden-Württemberg.
